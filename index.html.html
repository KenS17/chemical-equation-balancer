Chemical Equation Balancer

Balancing an equation is secretly a linear algebra problem: Ax = 0. This tool builds the matrix, solves it with Gauss-Jordan elimination (Exp 2) and shows every step.

Type an unbalanced equation

Use -> between sides, + between compounds, and brackets like Al2(SO4)3. Case matters (Co ≠ CO).

How it works (4 steps)

1. Each element gives one equation (atoms on left = atoms on right).
2. Write them as a matrix A: columns are compounds, product columns get a minus sign.
3. Row-reduce A with Gauss-Jordan elimination (with exact fractions).
4. The null space solution gives the smallest whole-number coefficients. A has a non-zero solution only because rank(A) < number of compounds (Exp 5).
